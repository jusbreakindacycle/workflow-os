# Freelancer Funnel

Workflow OS first serves a **service business funnel**, not a SaaS growth funnel.

```text
Lead
 -> Workflow Audit
 -> Automation Opportunity Score
 -> Paid Discovery / Automation Blueprint
 -> One High-ROI Pilot
 -> Before-vs-After Measurement
 -> Production Deployment
 -> Managed Automation Retainer
 -> Additional Workflows
 -> Reusable Client-Neutral Pattern
```

## Workflow audit inputs

Capture repetitive tasks, frequency, volume, manual minutes, systems, duplicate entry, approvals, wait time, error/rework rate, exceptions, and business impact.

The output is a prioritized opportunity list, not a promise to automate everything.

## Paid discovery outputs

- as-is process
- target process
- systems/interfaces
- rules and exceptions
- feasibility score
- risk assessment
- ROI estimate
- implementation recommendation
- pilot acceptance criteria

## Pilot selection

Prefer a workflow that is frequent, measurable, bounded, reversible, low-to-medium risk, and supported by stable interfaces.

## Retainer value

Monitoring, failure triage, provider/API changes, workflow optimization, agreed credential-rotation coordination, monthly ROI reporting, documentation updates, and an agreed new-workflow allowance.

## Productization loop

Every successful client workflow should be reviewed for reusable, client-neutral process patterns. Reuse logic and structure, never confidential client material.
