# Client Discovery Template

Use this as a structured interview. Do not assume the documented SOP matches reality.

## Business outcome

1. What result matters most?
2. Why now?
3. What happens if nothing changes?
4. How will we know the workflow improved?

## Process walk-through

Ask the operator to walk through the last real example from trigger to completion.

For each step capture:

- actor
- input
- action
- system
- output
- wait time
- exception
- handoff
- decision rule

## Repetition and volume

- frequency
- peak periods
- manual time/run
- backlog/wait
- rework rate

## Systems

For every system:
- official API/webhook?
- existing automation platform?
- identity/access owner?
- test/sandbox environment?
- export/import capability?
- known rate/provider restrictions?

## Judgment

Which decisions are exact rules? Which require interpretation? Which require legal/financial/customer judgment?

## Failure questions

- What can go wrong?
- How do you notice?
- What is safe to retry?
- What can accidentally happen twice?
- What is irreversible?
- What requires approval?
- What is the manual recovery procedure?

## Data

Classify data handled and identify minimum data necessary for automation.

## Ownership

Who:
- owns the business rule?
- approves production?
- manages access?
- responds when automation fails?
- receives reports?

## Pilot

Identify one bounded workflow with measurable baseline and acceptable blast radius.
